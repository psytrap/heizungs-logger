# Visual Indicators & Status Indicators in Documentation

## Rule
In internal documentation and markdown files, use clean visual emojis and status indicators (e.g., 📊, 📋, 🧭, 🎯, 🛡️, 🟢, 🟡, 🔴, 🔵, ✅, ⏳) in headings, status tables, and lists.

## Enforcement
- Ensure that icons enhance structure, status awareness, and quick scannability.
- Maintain plain, direct, and professional technical language.
- Never substitute icons for the canonical ticket identifiers (`T-NNN`) or for machine-readable front matter fields.
